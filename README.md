# 🔐 Random Password Generator

A simple and beginner-friendly **Random Password Generator** built using Python. This project generates strong and random passwords using a combination of uppercase letters, lowercase letters, numbers, and special characters.

## ✨ Features

* 🔐 Generates random passwords
* 🔢 Supports numbers
* 🔠 Includes uppercase letters
* 🔡 Includes lowercase letters
* 🔣 Includes special characters
* 📏 Allows the user to choose password length
* 🎲 Creates a different password each time
* 🐍 Simple Python implementation
* 🎓 Beginner-friendly project

## 🛠️ Technologies Used

* **Python 3**
* `random` module
* `string` module
* User input
* Conditional statements
* Loops
* Functions

## ⚙️ Installation

This project uses only Python's built-in modules, so **no external libraries are required**.

Make sure Python 3 is installed on your computer.

Check your Python version:

```bash
python --version
```

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/your-username/Random-Password-Generator.git
```

### 2. Open the project folder

```bash
cd Random-Password-Generator
```

### 3. Run the program

```bash
python password_generator.py
```
